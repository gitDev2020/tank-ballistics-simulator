# Галерея интерактивных симуляторов на чистом JavaScript (Vanilla JS)

В этом репозитории собраны мои самостоятельный проект, демонстрирующий работу со сложной математической логикой, симуляцией сред и высоконагруженными вычислениями на стороне клиента без использования сторонних библиотек.

## 1. Симулятор баллистики и многослойного бронирования (Танковый симулятор)

Интерактивное приложение для расчета пробития брони с учетом легирования стали, вязкости, твердости материалов и характеристик снаряда.

# Интерактивная аналитическая платформа симуляции массового электорального поведения

Проект представляет собой математическую модель симуляции социальных процессов и прогнозирования результатов голосования на чистом JavaScript (Vanilla JS) без использования сторонних библиотек.

## Основные фичи ядра:
* **Многоэтапный конвейер вычислений (Pipeline):** Расчет разделен на фазы `preProcess` (характеристики брони ДО удара), `takeDamage` (динамический урон по кастомным таблицам коэффициентов) и `postProcess` (остаточная энергия снаряда ПОСЛЕ пробития слоя).
* **Система модификаторов и эффектов (Armor Traits):** Реализованы физические свойства материалов: наклеп (`WorkHardening`), вязкость (`Viscosity`), хрупкость (`Fragility`), твердость (`Hardness`) и мягкость (`Softness`).
* **Механика усталости металла:** Учитывается текущее состояние слоя брони (`isDamaged`), при котором повторные удары рассчитываются по измененным формулам. Реализован мгновенный разрыв брони при превышении критического порога энергии.
